PROJECT NAME: NSP Estimating App

DESCRIPTION: Painting estimate and proposal generator for Northern Star Painters

COMPLETED FEATURES:
- Customer management
- Room/surface card layout with visual feedback
- Auto-calculation from room dimensions
- Primer system (toggle, product, coats, calculations)
- PDF generation with branded design
- Lead status system with filters
- Customer detail screen navigation
- Additional services per room
- Job profit tracking with percentages
- Multiple photos (4 per room)
- Signature capture
- Email PDF integration

TECH STACK: Single HTML file, Firebase backend, GitHub Pages deployment

REPO: amirzreik7-source/PWA-1
LIVE: https://amirzreik7-source.github.io/PWA-1
